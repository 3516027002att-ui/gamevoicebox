开麦匣 / GameVoiceBox 1.2.1 Windows 验收清单
适用：Windows 10 / 11 x64
编写日期：2026-10-06

状态说明
默认不设置任何全局快捷键，包括 14 条播放键和停止键；窗口内 Esc 停止保留。
这是待实机执行的验收模板。所有项目均未预先勾选，不代表已有 Windows 运行结果。
云端 Linux 核心测试、交叉构建和安装包静态核验应查看随附验证报告；不能据此把 UAC、驱动加载、真实设备音频、游戏前台热键或队友收音标为通过。
每项测试后填“通过 / 失败 / 未测 / 不适用”，写明证据或错误原文。需要 Windows 10 与 Windows 11 都确认时，在两套环境分别保存一份。
发现外发状态异常、啸叫或安全阻止时，先关闭发送、试听并停止测试；不关闭安全保护，不绕过反作弊。
