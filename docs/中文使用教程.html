WINDOWS 10 / 11 x64 原生一体安装版

开麦匣 / GameVoiceBox中文使用教程

把自己的麦克风和 14 段完整音效送进 VALORANT 队伍语音。先接好线路，再按住语音键播放。

默认不设置任何全局快捷键，包括停止键。14 条语音都能点击播放，也可以逐条自行绑定；留空表示不占用该全局键。窗口内 Esc 仍可停止音效。

版本：1.2.1 · 教程日期：2026 年 10 月 6 日 · Win32 原生界面 · 可离线阅读 · Ctrl+P 可打印

Windows 实机验收尚未完成。本教程给出操作步骤，不代表已经在 Windows 上验证安装、UAC、真实设备收音、游戏前台热键或队友收音。请配合随附的Windows 验收清单逐项确认；云端已测内容见随附验证报告。

先记住：音板发送选 CABLE Input，游戏输入选 CABLE Output，听声音仍用真实耳机。每次启动后，连接、发送和试听都要自己开启。

自己耳机里听不到音效时：连接成功不代表已开启试听或发送。先选择真实耳机，再勾选“耳机试听”，然后点击音效。发给游戏时勾选“开启发送”并按住游戏实际的语音键。两个都没勾选时，会提示“Enable send or headphone preview before playing a sound”，意思是先开启发送或耳机试听；不是设备已选错。每次启动仍默认关闭这两个开关，需要重新勾选。

1 认清麦克风和虚拟线

真实麦克风 + 14 段音效 → CABLE Input → CABLE Output → 游戏队伍语音

VB-CABLE 是 VB-Audio 的虚拟音频线。Input 是播放端，给音板写入声音；Output 是录音端，给游戏读取声音。这两个名字表示同一条线的两端。VB-Audio 官方说明

在哪里设置选择哪个设备
音板的真实麦克风实际说话的耳麦或 USB 麦克风
音板的发送输出CABLE Input (VB-Audio Virtual Cable)
音板的耳机试听（仅音效）实际戴着的耳机
VALORANT 的语音输入CABLE Output (VB-Audio Virtual Cable)
VALORANT 的语音输出实际戴着的耳机

设备名可能带编号，以完整名称和端点方向为准。不要把 CABLE Output 当作真实麦克风，不要把 CABLE Input 当作耳机试听（仅音效）。真实麦克风也不要选“立体声混音”或其他系统回环来源。

Windows 的播放输出继续使用耳机。无需把系统默认播放设备改成 CABLE Input，否则音乐、系统提示音等也可能进入虚拟线。音板不会替你修改 Windows 或游戏默认设备。

耳机试听只包含音效，不能用它判断麦克风有没有被游戏收到。游戏“回环测试”能检查完整输入线路，但测试后要关闭。

2 安装原生音板和官方驱动

确认系统和交付文件

  1. 在“设置 → 系统 → 关于”查看系统类型，确认是 Windows 10 或 Windows 11 x64。本音板不是 32 位 Windows、Windows ARM64 或 macOS 版本。
  2. 插好真实耳机和麦克风，先确认平时能正常说话和听声音，记住它们的名称。
  3. 保存手头工作，关闭游戏和其他正在录音的程序。安装虚拟驱动需要管理员确认，之后需要重启。
  4. 使用 GameVoiceBox-Setup-1.2.1-x64.exe 原生安装包。收到校验文件后，可在 PowerShell 用 Get-FileHash -Algorithm SHA256 检查该安装 EXE，逐字比对随附 SHA-256；校验只检查文件一致性，不能替代来源核验。

签名提示：自制音板 EXE 和一体安装包没有商业代码签名证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。这不等于已验证安全，也不能凭本教程保证 Windows 会放行。先核对来源和哈希；来源不明、被组织策略阻止或安全软件明确报错时，取消并记录提示。不需要关闭防病毒、SmartScreen、驱动签名检查或其他安全保护。

请使用仍在接收安全更新的 Windows 环境。音板的目标系统范围不代表系统本身仍有安全支持。

升级旧版、桌面入口和托盘

升级同一版本系列时，先彻底退出正在运行的音板；如果它已最小化到托盘，右击图标选“退出”。直接运行新版安装器并选择同一安装目录，已登记的旧版目录会保持不变，不会再套一层同名文件夹。设备、音量和已有快捷键设置保留，不需要先卸载；不要把三语音版和完整版放进同一个目录，两者需要独立安装目录。

安装会创建或修复当前 Windows 用户桌面上的音板快捷方式，图标和工作目录指向所选安装位置。若桌面写入失败，安装器会明确提示；可先从开始菜单或安装目录的 EXE 打开，确认桌面可写后重新运行安装器修复，不需要改动安全设置。

点击窗口的最小化按钮会最小化到托盘，原先已开启的发送、试听和快捷键继续工作。托盘可能在通知区域的隐藏图标内；点击／双击图标或右击选“恢复窗口”回到界面，右击选“退出”彻底关闭。窗口右上角“×”仍然退出。托盘图标创建失败时，程序会恢复可见窗口，避免隐藏后找不回来。

运行一体安装向导

  1. 双击原生版安装 EXE，按向导继续。音板按当前用户安装，默认放在 %LOCALAPPDATA%\Programs\GameVoiceBox。安装后从开始菜单或桌面的“开麦匣 / GameVoiceBox”打开程序。
  2. 阅读“官方虚拟声卡（可选）”页面。“启动官方 VB-CABLE 安装器（需要管理员确认）”默认不勾选。音板安装和驱动安装是两件事；只安装音板也可以先看界面和教程。
  3. 如果已经有标准 VB-CABLE，先跳过驱动安装。后面确认实际存在 CABLE Input 与 CABLE Output；仅有驱动服务记录不代表音频端点可用。
  4. 如果没有标准 VB-CABLE，再明确勾选启动官方安装器的选项。安装包携带标准 Pack45 的全部 31 个原样官方文件；完整源码 ZIP 另保留官方原始 VBCABLE_Driver_Pack45.zip，运行安装目录不重复存放该压缩包，启动的是官方 VBCABLE_Setup_x64.exe，不是自制驱动。
  5. Windows 弹出 UAC 管理员确认后，由你核对来源并决定是否继续。取消 UAC 或关闭官方安装窗口，不算完成驱动安装。
  6. 在官方窗口先阅读说明与许可。首次安装通常使用 Install Driver；如果显示 Remove Driver，先取消并检查已有设备，避免误卸载。按实际提示完成交互安装，不需要猜静默参数。
  7. 保存工作后手动重启 Windows。官方要求安装及卸载驱动后重启；音板向导不会强制重启。重启后打开音板，刷新设备并确认虚拟线两端实际出现。官方安装要求

以后需要安装时，可用音板里的“安装官方 VB-CABLE”按钮重新启动包内官方交互式安装器。缺少包内文件时，从官方产品页获取标准驱动，并按官方说明解压全部文件后以管理员方式运行 x64 安装器。不要只复制一个 Setup EXE。

安装后仍没有设备：先完成重启，再刷新。官方安装器显示错误时，保留原文并查官方支持，避免连续重复安装。关闭官方窗口或安装器返回，不是音板确认驱动可用的依据。

3 检查桌面应用麦克风权限

这是 Win32 桌面程序。连接线路、开启发送前，先确认 Windows 允许桌面应用读取真实麦克风：

  • Windows 11：“设置 → 隐私和安全性 → 麦克风”，检查“麦克风访问”“允许应用访问你的麦克风”和“允许桌面应用访问你的麦克风”。
  • Windows 10：“设置 → 隐私 → 麦克风”，检查此设备的麦克风访问、允许应用访问，以及“允许桌面应用访问你的麦克风”。

名称随系统版本可能略有不同，可从开始菜单搜索“麦克风隐私设置”。桌面程序未必有单独开关；桌面应用总开关也可能影响其他程序。公司电脑若设置被管理员锁定，请联系管理员。微软权限说明

修改后重新打开音板，重新选设备并连接。无需寻找浏览器网站权限或 Chromium 权限弹窗。

4 选择设备并连接

每次启动都不自动连接，发送和耳机试听都关闭。设备选择、音量、静音和快捷键可以记住，但开关状态不会恢复。打开程序后先检查麦克风是否静音，再主动连接。

  1. 点击“刷新设备”，查看当前可用的设备。USB 设备新插入、驱动重启后也先刷新。
  2. 在“真实麦克风”下拉框里选实际使用的麦克风，核对完整名称；不要选 CABLE Output 或其他回环来源。
  3. 在“发送到 CABLE Input”下拉框里明确选 CABLE Input (VB-Audio Virtual Cable)。发送输出不能用普通耳机代替。
  4. 需要自己试听时，在“耳机试听（仅音效）”里明确选真实耳机。不要选 CABLE Input / Output。
  5. 点击“连接所选设备”，等待状态显示连接成功。连接失败、权限被拒绝或设备格式不支持时，按状态提示排查，保持发送关闭。
  6. 先把音效音量调低，戴上耳机。需要自己听音效时，勾选“耳机试听”并点击“卡了”试一次。试听只放音效，不放麦克风。
  7. 准备把声音交给游戏时，勾选“开启发送”。确认状态实际显示发送已开启，再继续下一节配置游戏。

同名设备会附上稳定的设备编号，刷新顺序改变不会让已选设备改指向另一台。点击“设备详情”可查看完整名称和端点 ID；详情可横向/纵向滚动并复制，长名称不必靠下拉框截断内容猜测。线路身份根据驱动/适配器信息核对，修改显示名不会把 CABLE Output 变成真实麦克风；无法核对身份的设备会被拒绝。

界面在小屏幕或高 DPI 下可纵向滚动，Tab 导航会把获得焦点的控件滚入可见区域。正在打开发送或试听时再次点击相应开关会取消本次打开；勾选及状态文本以后台实际确认结果为准。

连接不等于发送。发送开启后，音板会把真实麦克风和当前音效写入虚拟线；是否传给队友还取决于游戏的输入设备和按键说话。发送关闭时，不再向虚拟线送声音。

只想自己试听，可以独立选择真实耳机并勾选“耳机试听”，无需先打开发送。试听始终只包含音效。

没有开启任何输出时，点击音效不会留在队列里等待下一次连接；以后打开发送或试听时，请重新触发需要的音效。

程序按你选定的设备端点连接，不会在设备失效时悄悄改用 Windows 默认麦克风或默认耳机。换设备后重新连接并检查开关状态，不要只看下拉框以为线路已经可用。

5 配置 VALORANT 和回环测试

选好输入和输出

  1. 打开游戏“设置 → 音频 → 语音聊天”（Settings → Audio → Voice Chat）。
  2. 输入设备 / Input Device：明确选 CABLE Output (VB-Audio Virtual Cable)，不要依赖默认设备。
  3. 输出设备 / Output Device：选真实耳机。游戏和队友声音继续从耳机播放。
  4. 打开“队伍语音聊天 / Team Voice Chat”，检查队伍按键说话的实际绑定。默认是 V；改过就用自己的键。

先自行绑定需要的播放键，再在游戏前台按住 V、触发该键，等完整音效结束后再松开 V。默认没有播放或停止的全局键。也可在音板窗口点击播放，但切换窗口可能影响游戏的按键说话，应另外实测。音板不注入按键，也不会替你按住 V。队伍语音的默认键和按键说话规则见Riot 官方语音说明。

第一次先检查完整线路

  1. 戴上耳机，暂时关闭音板的耳机试听，避免同时听到两份音效。确认音板发送已开启。
  2. 在游戏语音设置打开 Loopback Test / 回环测试。正常说一句话，应听到自己的声音。
  3. 逐一点击 14 条音效并完整听完，名称和时长见下一节。需要调整时，一次只改音效或麦克风的一个音量。
  4. 测试完立即关闭 Loopback Test。正常使用时不要长期打开；之后如需自听音效，再打开音板耳机试听。
  5. 找愿意配合的队友做一次短测试：保持游戏在前台，按住 V 说话，再按一次播放键，确认对方听到完整音效、正常麦克风和没有回声。

回环是本地检查；回环能听到，不保证队伍语音已经通畅。前台热键和实际队友收音都需要另外确认。游戏更新后的名称或界面位置可能略有变化，以实际设置为准。

14 条音效在可滚动列表中逐条显示，均可点击播放。一次只播放一段：触发另一段会替换当前音效，重复触发同一段会从头再播；不循环、不把多段叠在一起。按住播放键不会靠键盘自动重复连续播放。

运行时使用完整第一音轨解码的 48 kHz、双声道、PCM16 WAV。原始文件仅保留在源代码包 assets/original，安装器只携带运行 WAV 和校验元数据。8 个原文件虽然扩展名是 MP3，实际是含 AAC 音轨的 MP4/M4A；其中 4 个还含视频，视频不会进入运行文件。表中时长按实际 PCM 帧数计算，未裁剪或修改播放速度；停止时已经送进音频设备缓冲的极短尾声，可能不会在按键瞬间消失。

分别控制麦克风和音效

  • 音效音量：影响虚拟线里的音效，也影响耳机试听。先调低，避免音效盖过说话声。
  • 麦克风音量：只影响真实麦克风进入虚拟线的音量。正常说话清楚即可；过响或失真时，适当降低输入设备或音板音量。
  • 麦克风静音：只把麦克风从混音里静音，音效仍可发送。取消静音恢复原先麦克风音量，不需要把滑块重新拉回。
  • 关闭发送：同时停止麦克风和音效进入虚拟线，并清空该发送流；耳机试听可以继续。要关闭所有音板声音，也把试听关掉。

“停止音效”不是“关麦”；“麦克风静音”也不是“停止音效”。游戏在前台时，先自行绑定全局停止键，再用该键停止音效；游戏自己的 Esc 不受音板窗口内快捷键影响。

原生版不额外实现 Chromium 的回声消除或降噪。Windows 或设备已有的麦克风处理仍可能生效。建议戴耳机，关闭 Windows“侦听此设备”和正常使用时的游戏回环；不要用外放扬声器把音效再录回麦克风。

7 设置可选全局快捷键

默认不设置 14 条播放键，也不设置全局停止键。所有输入框可留空；留空表示不注册、不占用该全局键。没有全局绑定时，用列表按钮播放、“停止音效”按钮停止，或在音板窗口按 Esc 停止。

  1. 滚动到需要的音效，在对应输入框填组合，例如 Ctrl+Alt+1 或 Shift+F8。只给常用音效绑定即可，其余保持空白。
  2. 需要在游戏前台随时停止时，另填可选的停止音效快捷键，例如 Ctrl+Shift+S。停止键和各播放键都可编辑或清空。
  3. 每个组合用一个主键，可搭配 Ctrl、Alt、Shift；主键可用单个英文字母、数字或 F1–F24（F12 除外）。所有非空组合必须彼此不同，播放键也不能与停止键重复。
  4. 点击“保存全局快捷键”，看实际注册状态和保存提示。Windows 已占用的组合、重复或无效格式会报错；失败后程序尝试恢复旧键。
  5. 确认自己设置的非空键显示已注册，再到游戏前台分别测试。空白键显示未绑定是正常情况；有文字但未注册时，不能用它触发。清空并保存后，旧全局键应被注销。

F12 不能使用：Windows 将它保留给调试器，含 F12 的组合也会被拒绝。不带修饰键的 Esc/Escape 也会被拒绝，保留给音板窗口内停止，避免占用游戏自己的 Esc。优先使用 Ctrl / Alt / Shift 组合。微软全局热键规则

其他音板、语音软件、录屏工具或游戏绑定都可能冲突。先改用没有冲突的组合，再测试。不要把播放键改成 V，以免与队伍按键说话混在一起。

“注册成功”表示 Windows 接受了全局键，还需确认当前游戏前台能收到对应触发。无需关闭反作弊或降低安全设置，也不要用键盘注入绕过游戏限制。

若设置写入失败，记录原文，不要把当前可用状态当作已永久保存。下次启动后重新核对设备、音量和实际热键状态；设置文件损坏恢复默认后，全部全局键再次为空。

8 无声 回声和设备断开

切到游戏后无声：先看热键诊断

窗口底部“热键诊断”保留最近一次已注册全局键的名称、本地时间和接收 / 处理 / 提交 / 拒绝累计次数。接收表示主消息队列收到该热键；处理表示窗口过程收到；提交表示控制器接受命令，不代表已出声。被拒绝时会保留拒绝原因。切回窗口、刷新设备或后续音频状态更新不会清掉这条记录，重启后归零。

  1. 确认测试键已注册，例如你自行设置的 Z。选择真实耳机、开启耳机试听，先在游戏外按一次，记下诊断次数。
  2. 切到游戏前台再按一次同一键，然后切回音板，滚动到底部，截下诊断和发送/试听状态；不要切回后再按测试键，以免覆盖最近事件。
  3. 接收次数未增加：这次测试没有在主消息队列观察到对应热键。接收增加但处理不增加：记录两组次数。处理增加而提交不增加：查看拒绝原因或是否仍在等待提交结果。提交增加但没听到：继续核对试听输出、音量和音频状态。以上结果用于分层排查，不能单凭它认定游戏、反作弊或设备的原因。

诊断只统计本程序已注册的播放/停止全局键，不记录其他按键或输入内容，不会保存日志或上传。请保留游戏内外各一次测试的截图和当时是否听到声音。

耳机听到音效 但游戏或队友听不到

  1. 耳机试听只证明试听线路。检查“开启发送”是否真的开启，线路状态是否有错误。
  2. 重新核对：音板发送为 CABLE Input，游戏输入为 CABLE Output，游戏输出为真实耳机。
  3. 先做游戏回环。回环正常后，确认队伍语音已启用，并在真实测试时按住 V 到整段播放结束。
  4. 回环正常但队友仍听不到，查看游戏语音状态和当前账号/地区的语音可用性，按 Riot 官方支持排查；不要从此推断音板已通过队友收音验收。

音效正常 但自己的说话没有声音

  1. 检查音板“麦克风静音”、麦克风音量、耳麦物理静音键和 Windows 输入音量。
  2. 核对真实麦克风名称，检查桌面应用麦克风权限。用 Windows 声音设置观察说话时输入电平。
  3. 退出其他占用麦克风的软件，重新连接线路。权限、设备格式或占用错误时，保留音板显示的原文。

只有说话 没有音效

先点击窗口中的“卡了”，确认音效音量不为零且发送开启。按钮有效、热键无效时，检查注册状态、组合冲突和游戏前台测试；默认没有全局键，要先绑定并保存；笔记本的功能键可能需要 Fn 配合，也可改用 Ctrl+Alt+数字。

出现两份声音 回声或啸叫

  1. 游戏回环开启时，关闭音板耳机试听；完成回环后把游戏回环也关闭。
  2. 在 Windows“更多声音设置 / 声音控制面板 → 录制 → 设备属性 → 侦听”中，确认相关设备没有勾选“侦听此设备”。不要用它额外连接虚拟线。
  3. 确认真实麦克风没有选到 CABLE Output。戴耳机并关闭外放，降低音量后再试。

USB 拔出 驱动重启或默认设备改变

  1. 选定的麦克风或发送端失效时，程序应关闭相关发送并提示错误；试听设备失效应关闭试听。看实际状态，暂时不要继续触发。
  2. 重新插好设备，点击“刷新设备”，重新选择确切的麦克风、CABLE Input 和真实耳机。
  3. 重新连接，确认成功，再主动打开发送或试听。插回后不应自动恢复外发声音。
  4. 只修改 Windows 默认设备时，音板应继续指向原先明确选定的端点。要用另一设备，必须自己选择并重新连接；不会静默改路由。

列表里名称相似或重复时，先确认哪个是实际设备；可逐个查看 Windows 声音设备信息。不确定时保持发送关闭。遇到不支持的设备格式时，程序应拒绝连接并报错；不要随意修改其他程序的全局音频设置。

持续使用后延迟增加 或声音断续

先停止测试，记录使用多久、各设备名称、是否更改了采样率或重新插拔，以及状态错误。关闭发送后重新连接可作排查。云端的时钟漂移模拟不能代替真实硬件长时间测试；请在验收清单记录实机表现。

9 恢复真实麦克风和卸载

不用音板时恢复正常语音

  1. 关闭发送和耳机试听，退出音板。退出会释放程序持有的麦克风与音频流。
  2. 在 VALORANT“设置 → 音频 → 语音聊天”把输入设备手动改回真实麦克风，输出继续用真实耳机。
  3. 按住队伍语音键说一句话，确认普通语音恢复。如果其他语音软件也选了 CABLE Output，同样手动改回。

退出音板不会自动改回游戏输入。如果游戏仍选 CABLE Output，而音板已经关闭，游戏通常就没有这条线路的输入。音板也不会替你恢复或修改 Windows 默认设备。

卸载音板

先退出，再从 Windows“设置 → 应用”找到“开麦匣 / GameVoiceBox”运行卸载，或运行安装目录内的卸载程序。

卸载只删除清单内的音板文件，不会自动卸载已安装的共享 VB-CABLE 驱动；会保留用户设置和自行添加的文件。原生版设置保存在 %APPDATA%\GameVoiceBox\settings.ini。保留设置是正常行为。

确定其他软件也不再需要 VB-CABLE 时，才自行按官方说明用官方安装器卸载驱动，并按要求重启。不要为解决一个音板问题就随意移除共享驱动。
